# Monetization: on-device features are free, server features are Pro

We gate features by capability, not by artificial limits: anything that can run fully
on-device (import, parsing, categorization, dedup, reconciliation, the manual column-mapper,
analytics, search, export) is **free**, and anything that requires a server (AI
parsing/assist, one-click Account Aggregator onboarding, cross-device sync) is **Pro**.
This keeps the privacy promise (free = on-device) aligned with the cost structure (only
server-backed features incur server cost) and makes the free/paid line predictable for both
users and contributors.
